# Python Starter Projects

Commented starter code for kids: a Quiz app, Pong, Snake, and a Paint app.
Open `index.html` (or the GitHub Pages link) to copy any starter.

## Put it on GitHub Pages

1. Create a new public repository on GitHub, for example `python-starters`.
2. Upload every file in this folder (`index.html`, `README.md`, and the four `.py` files).
3. In the repository, go to **Settings → Pages**.
4. Under **Branch**, pick `main` and `/ (root)`, then **Save**.
5. After a minute, the page is live at `https://<your-username>.github.io/python-starters/`.

Put that link on the handout.

## Where kids run the code

- `quiz.py` runs in any Python editor, including Code.org Python Lab.
- `pong.py`, `snake.py`, and `paint.py` use turtle graphics with keyboard and mouse.
  Run them in IDLE (included with Python) or another editor that supports turtle.
  Test one in your chosen editor before class.
